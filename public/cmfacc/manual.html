1. เข้าสู่ระบบ

/cmfacc/index.html → Supacha / รหัสผ่าน → สาขา CM2 มุมขวาบน → ตรวจ D1: พร้อม มุมซ้ายบน

2. Dashboard

สรุป AR/AP/VAT/WHT real-time, กราฟ 6 เดือน, งบทดลอง, ปุ่มลัด พิมพ์งบทดลอง / ภพ.30 / ภงด.53

3. ข้อมูลพื้นฐาน

1.1 แก้ชื่อบริษัท/เลขภาษี/ที่อยู่/VAT%/WHT%/คำนำหน้าเลขที่ → PUT /api/system-params
1.2 เพิ่มลูกค้า POST /api/customers / เจ้าหนี้ POST /api/vendors / ดูผังบัญชี GET /api/chart-accounts
1.3 รายงานสรุป — กำไรขาดทุน/งบดุล/Aging

4-6. AR/AP/FIN

2.1 ข้อมูลพื้นฐาน: รายได้, ประเภทลูกหนี้ และช่วงอายุลูกหนี้ แสดงช่องข้อมูลที่ไม่ซ้ำกัน — กรอก/ค้นหาตามชื่อรายการ แล้วกด + เพิ่ม เมื่อสร้างรายการใหม่
2.2-2.5: ปุ่ม + สร้างเอกสาร → วันที่, ประเภท INV/REC/CN/DN, ชื่อคู่ค้า*, ยอดก่อน VAT*, VAT/WHT → คำนวณอัตโนมัติ → POST /api/documents → PDF ไทยพร้อมโลโก้ → ผ่านรายการ GL POST /api/documents/:id/post

7. ภาษี

5.1 WHT → + ออกหนังสือรับรอง ภงด.3/53 → POST /api/tax/wht → PDF
5.2 VAT → เลือกเดือน พ.ศ. → คำนวณ GET /api/reports/vat → PDF ภ.พ.30

8. GL

6.1 JV → เพิ่มบรรทัด บัญชี/เดบิต/เครดิต (ต้องสมดุล) → POST /api/gl-entries → PDF
6.2 งบทดลอง GET /api/reports/trial-balance
6.3 ปิดงวด POST /api/accounting-periods/:period/close

9. สินค้าคงคลัง

7.1 + เพิ่มสินค้า POST /api/inventory → ถัวเฉลี่ย → 📄 Stock Card / PDF สรุป
7.2 เคลื่อนไหว POST /api/inventory/moves

10. เจ้าหน้าที่ระบบ

admin/account/staff/viewer — POST /api/users — ห้ามลบ Supacha

11. เวิร์กโฟลว์

สร้าง draft → ตรวจ VAT/WHT → บันทึก → ผ่าน GL → พิมพ์ PDF (TH Sarabun + โลโก้) → ยกเลิก void กลับรายการ → ปิดงวด

12. FAQ

บันทึกไม่ได้ → เช็คชื่อ/ยอด/เดบิต=เครดิต, Toast แดง, D1 พร้อม, งวดปิด 403
โลโก้ไม่ขึ้น → เน็ต/CORS, R2 ปิด → uncomment [[r2_buckets]] แล้ว wrangler deploy
