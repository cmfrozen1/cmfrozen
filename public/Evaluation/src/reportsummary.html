วิทยากร   คุณ
ข้อมูลการประเมินผล (ผู้เข้าอบรม) คะแนนเฉลี่ย
1   การประเมินผลเนื้อหาการสัมมนา
1.1   ก่อนการอบรม / สัมมนา ท่านมีความรู้ในเรื่องนี้
1.2   หลังการอบรม / สัมมนา ท่านมีความรู้เพิ่มขึ้น
1.3   ท่านได้รับความเข้าใจ / เนื้อหาวิชาที่ได้รับสามารถนำไปใช้ได้
1.4   ระยะเวลาในการอบรม / สัมมนาเหมาะสม
1.5   เอกสารประกอบการฝึกอบรมสัมมนา
2   การประเมินผลวิทยากร
2.1   วิธีการถ่ายทอดความรู้ / การยกตัวอย่างประกอบมีความชัดเจน
2.2   การสร้างบรรยากาศ / การมีส่วนร่วม / การกระตุ้นให้ผู้ฟังได้ใช้ความคิด
2.3   ภาษาและคำพูดที่ใช้ในการบรรยาย / การตอบคำถามชัดเจน
2.4   การตรงต่อเวลา
3   การประเมินผลการดำเนินงานของผู้จัดอบรมสัมมนา
3.1   สถานที่และสภาพแวดล้อมในการสัมมนามีความเหมาะสม
3.2   ความพร้อมของอุปกรณ์โสตทัศนูปกรณ์ต่าง ๆ
3.3   อาหาร และเครื่องดื่ม
3.4   ความชัดเจนในการชี้แจงรายละเอียดต่าง ๆ
3.5   ความกระตือรือร้นในการให้บริการ / ช่วยเหลือ
ภาพรวมของหลักสูตร
การประเมินผลผู้เข้าอบรม ( หัวหน้างาน )
มีทัศนคติในการทำงานเชิงบวก สามารถปรับเปลี่ยนพฤติกรรมในการทำงาน ในทางที่ดีขึ้น
เพิ่มประสิทธิภาพการปฏิบัติงานในหน้าที่ที่ได้รับผิดชอบดีขึ้น
ประสานงานร่วมกับผู้อื่นหรือหน่วยงานที่เกี่ยวข้องได้อย่างมีประสิทธิภาพ
สามารถนำความรู้ / ทักษะที่ได้รับจากการอบรมไปใช้ในการทำงานหรือแก้ไขปัญหาได้
สามารถสร้างสรรค์แนวคิดใหม่ๆ ในการทำงานและนำความรู้ไปเผยแพร่หรือถ่ายทอดได้
มีความพึงพอใจกับการส่งพนักงานเข้าอบรมในหลักสูตรนี้
