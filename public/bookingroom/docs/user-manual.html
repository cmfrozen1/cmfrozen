01ภาพรวมของระบบ

ระบบจองห้องประชุมนี้เป็นแอปพลิเคชันที่ทำงานบนแพลตฟอร์ม LINE ทั้งหมด ผู้ใช้ไม่ต้องติดตั้งแอปเพิ่ม เพียงมีบัญชี LINE ก็สามารถจองห้องประชุม ติดตามสถานะ และรับการแจ้งเตือนได้ครบวงจร

สถาปัตยกรรมการทำงาน

📱LINE MiniApp / LIFFหน้าเว็บแอปสำหรับจองห้อง ดูปฏิทิน จัดการการจอง
💬LINE Botรับคำสั่งทางลัด ส่ง Flex Message และปุ่มอนุมัติในแชท
⚙️Google Apps ScriptBackend ประมวลผล API ทั้งหมด + Triggers อัตโนมัติ
🔥Firebase RTDBฐานข้อมูลกลางเก็บผู้ใช้ ห้องประชุม การจอง และการแจ้งเตือน

องค์ประกอบหลักของระบบ

📅

ระบบจองห้อง

จองล่วงหน้า ระบุวัน–เวลา หัวข้อประชุม รูปแบบประชุม (ออนไซต์/ออนไลน์) อุปกรณ์ที่ต้องการ และรองรับการจองข้ามวัน (Multi-day)

🗓️

ปฏิทินการจอง

แสดงวันที่มีการจองด้วยสีตามสถานะ (รออนุมัติ/อนุมัติแล้ว/ยกเลิก) พร้อมแถบเชื่อมการจองข้ามวันและ Modal สรุปรายการต่อวัน

🔔

ระบบแจ้งเตือน

แจ้งคำขอจองใหม่ไปยังผู้ดูแล, แจ้งผลอนุมัติกลับผู้จอง, แจ้งเตือนก่อนประชุม และสรุปการใช้ห้องรายวัน/รายเดือน

🛡️

ระบบสิทธิ์การใช้งาน

แบ่งสิทธิ์ 4 ระดับ — ผู้ดูแลระบบ, ผู้ดำเนินการ, ผู้ใช้งาน และผู้เยี่ยมชม โดยเมนูและข้อมูลจะแสดงตามสิทธิ์โดยอัตโนมัติ

💡 หลักการสำคัญ ข้อมูลทั้งหมดถูกเก็บศูนย์กลางไว้ที่ Firebase Realtime Database ทำให้ไม่ว่าผู้ใช้จะดำเนินการผ่าน LINE Bot หรือ MiniApp ก็จะเห็นข้อมูลล่าสุดเสมอและตรงกันทั้งสองช่องทาง

02การเริ่มต้นใช้งาน

การเข้าใช้งานครั้งแรก

  1. เพิ่มเพื่อน LINE Bot ของระบบจองห้องประชุม (QR Code / Link จากฝ่าย IT)
  2. เมื่อทัก Bot ครั้งแรก ระบบจะลงทะเบียนผู้ใช้อัตโนมัติจากโปรไฟล์ LINE ของคุณ และส่งข้อความต้อนรับพร้อมวิธีใช้งาน
  3. แตะปุ่ม เปิดแอปจองห้อง เพื่อเข้าสู่ LINE MiniApp (LIFF) — ระบบจะยืนยันตัวตนผ่าน LINE โดยอัตโนมัติ ไม่ต้องกรอก Username/Password
ℹ️ ผู้ใช้คนแรกของระบบ บัญชีแรกที่ลงทะเบียนจะได้รับสิทธิ์ ผู้ดูแลระบบ (Admin) โดยอัตโนมัติ บัญชีถัดไนจะเป็น ผู้ใช้งาน (User) ซึ่ง Admin สามารถปรับระดับสิทธิ์ในภายหลังได้

การเชื่อมโยงบัญชี (User Linking)

หากคุณใช้งานผ่านหลายอุปกรณ์หรือหลายบัญชี LINE ระบบจะเชื่อมโยง User ID เข้าด้วยกันโดยอัตโนมัติ ทำให้การจองและการแจ้งเตือนตามหาตัวคุณเจอเสมอ ไม่ว่าจะทักจากทางไหน

ข้อมูลโปรไฟล์ของคุณ

  • ระบบดึง ชื่อแสดงและรูปโปรไฟล์ จาก LINE อัตโนมัติ
  • ควรเพิ่ม อีเมล, เบอร์โทร และแผนก ในหน้าโปรไฟล์ของ MiniApp เพื่อให้ผู้ดูแลติดต่อสอบถามได้ง่าย
  • สามารถเปิด/ปิด การแจ้งเตือนส่วนตัว ได้จากหน้าโปรไฟล์ (ค่าเริ่มต้นคือเปิด)

หน้าจอหลักของ MiniApp

เมนูล่าง (Bottom Nav)สิ่งที่ทำได้
🏠 หน้าแรกปฏิทินจองรายเดือน, สถิติ (ห้องทั้งหมด/จองวันนี้), ปุ่มลัด จองด่วน–วันนี้–ห้องว่าง และค้นหารายชื่อห้อง
📅 การจองของฉันรายการจองของตัวเอง กรองตามสถานะ พร้อมปุ่มแชร์และยกเลิก
➕ จองห้องเปิดฟอร์มสร้างคำขอจองใหม่
🔔 แจ้งเตือนประวัติการแจ้งเตือนของคุณ (อ่านแล้ว/ยังไม่ได้อ่าน)
🛠️ จัดการระบบ Admin / Operatorอนุมัติคำขอ, จัดการผู้ใช้, จัดการห้อง, ตั้งค่าระบบ (แสดงตามสิทธิ์)

การจองดูรายการจองของตัวเองทั้งหมด

รออนุมัติรายการที่ยังรอการอนุมัติ (สำหรับผู้มีสิทธิ์อนุมัติ)
helpข้อความช่วยเหลือการใช้งาน

Flex Message แจ้งเตือนอัตโนมัติ

Bot จะส่งการ์ดข้อความ (Flex Message) ที่มีข้อมูลครบ ห้อง / วันที่ / เวลา / ผู้จอง / สถานะ ในแต่ละเหตุการณ์:

  • 🟢 คำขอจองใหม่ → ส่งถึง Admin พร้อมปุ่ม อนุมัติ/ยกเลิก กดตัดสินใจได้ทันทีในแชท
  • ✅ ยืนยันการจองแล้ว → แจ้งผู้จองเมื่อคำขอได้รับอนุมัติ
  • 🔴 ไม่อนุมัติ / ถูกยกเลิก → แจ้งผู้จองพร้อมปุ่ม "จองใหม่"
  • 🔵 แจ้งเตือนก่อนประชุม → แจ้งล่วงหน้าตามระยะเวลาที่ตั้งค่า พร้อมปุ่มเข้าลิงก์ประชุม (ถ้ามี)
  • 🟡 ระบบยกเลิกอัตโนมัติ → แจ้งเมื่อรายการเลยเวลาและยังไม่ได้รับอนุมัติ
💡 การแชร์รายการจอง จากการ์ดรายละเอียดใน MiniApp มีปุ่ม "แชร์ไปยังกลุ่ม" เพื่อส่งต่อข้อมูลการประชุมให้ผู้เข้าร่วมทราบผ่าน LINE ได้โดยตรง
⚠️ การปิดรับแจ้งเตือนส่วนตัว หากคุณปิดการแจ้งเตือนในหน้าโปรไฟล์ ระบบจะไม่ส่งการแจ้งเตือนส่วนตัว แต่การบันทึกการจองยังทำงานปกติ (หากบันทึกสำเร็จแต่ส่งแชทไม่สำเร็จ ระบบจะแจ้งเตือนบนหน้าจอให้ทราบ)

04การใช้งาน MiniApp

ปฏิทินการจอง (หน้าแรก)

  • สีของวันที่ บอกสถานะการจอง: 🟡 รออนุมัติ · 🟢 อนุมัติแล้ว · 🔴 ยกเลิก/ปฏิเสธ
  • แถบเชื่อมสี (Multi-day bar) ลากต่อเนื่องคลุมช่วงวันที่จองข้ามวัน มุมโค้งที่วันเริ่ม–วันสุดท้าย
  • แตะวันที่ที่มีการจอง → เปิด Modal สรุปรายการจองทั้งหมดของวันนั้น พร้อมแตะเข้ารายละเอียด หรือกดปุ่ม จองวันที่นี้ เพื่อสร้างคำขอจองใหม่ทันที
  • ปุ่มลูกศร ◀ ▶ เปลี่ยนเดือน · ปุ่ม วันนี้ กลับมาที่วันปัจจุบัน

สร้างคำขอจองใหม่

  1. เลือกห้องประชุมจากรายการ (หรือกด "จองด่วน")
  2. เลือกวันที่เริ่ม–สิ้นสุด (จองหลายวันต่อเนื่องได้) และเวลาเริ่ม–เวลาสิ้นสุด — ระบบจะตรวจความพร้อมใช้งานแบบเรียลไทม์และแจ้งทันทีหากชนกับรายการอื่น
  3. กรอกหัวข้อการประชุม (ไม่เกิน 100 ตัวอักษร) และรายละเอียด (ไม่เกิน 500 ตัวอักษร)
  4. เลือกรูปแบบประชุม:
    • ออนไซต์ — เลือกใช้คอมพิวเตอร์/โปรเจคเตอร์ได้
    • ออนไลน์ — เลือกอุปกรณ์ กล้อง/ไมค์/คอมพิวเตอร์ และใส่ลิงก์ประชุม (Zoom, Teams ฯลฯ) ได้
  5. กดบันทึก — คำขอจะเข้าสู่สถานะ รออนุมัติ และแจ้งผู้ดูแลระบบทันที

การจองของฉัน

ดูรายการจองทั้งหมดของตัวเอง กรองตามสถานะ (ทั้งหมด / อนุมัติแล้ว / รออนุมัติ / ยกเลิก / ปฏิเสธ / ระบบยกเลิก) สามารถยกเลิกการจองของตัวเองได้จากรายละเอียดรายการนั้น

ℹ️ การตรวจสอบเวลาว่าง ระบบตรวจสอบทั้งการจองปกติและการจองข้ามวัน (Multi-day) ก่อนอนุญาตให้บันทึกเสมอ จึงมั่นใจได้ว่าห้องจะไม่ถูกจองซ้ำในช่วงเวลาเดียวกัน

สถานะความหมาย / สาเหตุ

อนุมัติแล้วAdmin/Manager อนุมัติ — ผู้จองได้รับแจ้งทันที
ปฏิเสธผู้ดูแลไม่อนุมัติ (เช่น ชนเวลากิจกรรมสำคัญ) — แนะนำให้จองช่วงใหม่
ยกเลิกผู้จองยกเลิกเอง หรือถูกยกเลิกโดยผู้ดูแล
ระบบยกเลิกรายการยังไม่ได้รับอนุมัติและเลยเวลานัดหมายไปแล้ว — ระบบยกเลิกอัตโนมัติทุก 30 นาที
เสร็จสิ้นการจองที่อนุมัติแล้วและเวลาผ่านไปเรียบร้อย

เงื่อนไขการอนุมัติ

  • หาก Settings ของระบบเปิดใช้ "ต้องอนุมัติก่อนใช้งาน" ทุกคำขอต้องรอ Admin อนุมัติก่อนถึงจะถือว่าจองสำเร็จ
  • การอนุมัติ/ปฏิเสธทำได้ 2 ช่องทาง: ปุ่มในการ์ด LINE หรือผ่านแท็บ"รออนุมัติ"ใน MiniApp
  • ทุกการเปลี่ยนสถานะจะบันทึก Notification log ให้ผู้จองเสมอ ตรวจสอบย้อนหลังได้ในเมนูแจ้งเตือน
⚠️ ข้อควรระวัง — Auto Cancel ระบบยกเลิกอัตโนมัติเฉพาะรายการที่ "ยังไม่ได้รับอนุมัติ" เมื่อถึง/เลยเวลาเริ่มประชุม รายการที่อนุมัติแล้วจะไม่ถูกยกเลิกโดยระบบ ดังนั้น Admin ควรตรวจคิว "รออนุมัติ" สม่ำเสมอ

  • 🧰 ผู้ดำเนินการ (Manager/Operator): ดูแลการจองและห้องประชุมได้ครบ รวมถึงอนุมัติรายการผ่าน LINE Bot / สรุปรายวัน แต่จะไม่เห็นแท็บ รออนุมัติ, จัดการผู้ใช้ และการตั้งค่าระบบ

07ระบบอัตโนมัติ (Triggers)

Google Apps Script ทำงานเบื้องหลังตามตารางเวลาอัตโนมัติ 4 งาน โดยไม่ต้องมีคนกดสั่ง

Triggerความถี่หน้าที่
🔔 Meeting Reminders ทุก 10 นาที ตรวจการจองที่ใกล้ถึงเวลาและส่งแจ้งเตือนล่วงหน้าตามค่าที่ตั้งในระบบ (เช่น 30 นาที / 1 ชม. / 1 วันก่อนประชุม) ให้ผู้จองและผู้ดูแล
🤖 Auto Cancel Overdue ทุก 30 นาที ยกเลิกเฉพาะรายการที่ ยังไม่ได้รับอนุมัติ เมื่อเลยเวลา แล้วแจ้งผู้จองพร้อมปุ่ม "จองใหม่"
📊 Monthly Summary ทุกวัน เวลา 20:00 น.
(ส่งจริงเมื่อสิ้นเดือน)		 รวบรวมสถิติการจองรายเดือนและส่งสรุปให้ผู้ใช้ทุกคน / Broadcast ให้ Admin ส่งเองได้
🧹 Cleanup Inactive Users ทุกวัน เวลา 03:00 น. ลบ/ปรับสถานะผู้ใช้ที่ไม่มีการใช้งานหรือเลิกติดตาม Bot เพื่อคงความสะอาดของฐานข้อมูล

การตรวจสอบสถานะ Triggers

Admin สามารถกดปุ่ม "ตั้งค่า Triggers" ในแท็บการตั้งค่าเพื่อสร้าง/สร้างใหม่ทั้ง 4 งาน ระบบจะบันทึกสถานะการตั้งค่าลง Firebase และแสดงผลในกล่อง Trigger Status ให้ตรวจสอบได้ทันที
